1Introduction
Odds feed is an automated service which enables your betting system or website access to our Live Odds on all major sporting events through XML Odds feed. This service is already being used successfully by other customers who confidently give their full approval and praise the time savings and accuracy of the content.

3How to
You will be provided an XML Feed URL to get full Odds data with the format as below:
${Domain}/feeds/${UserName}/odds.xml
3.1Using timestamp
To get the latest changes of Odds only, you need to specify the biggest timestamp in your previous data request then input this parameter in the query string. Please, note that this timestamp must be retrieved from child node only.
${Domain}/feeds/${UserName}/odds.xml?t=[timestamp]
3.2Using compression algorithm
To reduce the consumption of resources such as transmission bandwidth, you need to use the data compression algorithm and currently we support 2 algorithms:
  • zip=deflate: zip the xml stream using deflate algorithm
  • zip=gzip: zip the xml stream using gzip algorithm
All you need to do is to input the algorithm name in the query string as below:
${Domain}/feeds/${UserName}/odds.xml?zip=[algorithm-name]

Note: In case of using both parameters: ${Domain}/feeds/${UserName}/odds.xml?t=[timestamp]&zip=[algorithm-name]
